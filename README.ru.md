# 🌀 Iluzion v35.0

**Iluzion** — это многофункциональный инструмент для оптимизации игр и улучшения интерфейса для Windows. Набор утилит для улучшения игрового опыта, особенно в Roblox.

> **Примечание:** Проект находится в активной разработке. Некоторые функции могут быть неполными или изменяться.

---

## ✨ Возможности

*   **🚀 Турбо-режим:** Повышает приоритет выбранного окна (Высокий или Обычный) для лучшей производительности.
*   **🖥 Растяжение:** Включает растяжение экрана по аналогии с CS:GO (работает через реестр Windows).
*   **🌀 Motion Blur:** Динамическое размытие, основанное на скорости движения мыши.
*   **📊 FPS & Пинг Оверлей:** Кастомный оверлей для отображения FPS (для Roblox) и пинга сети.
*   **🎯 Кастомный Прицел:** Полностью настраиваемый прицел (Крестик, Точка, Круг, Треугольник или Своё изображение) поверх всех окон.
*   **⌨️🖱 Виджет Ввода:** Отображение нажатий клавиш (WASD, Пробел, Shift, Ctrl) и кликов мыши (ЛКМ, ПКМ, Средняя кнопка).
*   **🌙 Яркость Экрана:** Прямая регулировка яркости монитора.
*   **📸 Скриншоты:** Создание скриншота с 3-секундным таймером.
*   **🎥 Запись Экрана:** Скоро
*   **💬 Обратная Связь:** Отправка отзывов или отчетов об ошибках в Google Форму.
*   **🌍 Мультиязычность:** Поддерживаются английский и русский языки. Язык выбирается при первом запуске.
*   **💾 Система Конфигов:** Сохранение, загрузка и удаление пользовательских конфигураций.

## 🛠 Требования и Установка

### Предварительные требования

*   **Windows OS** (7/8/10/11)
*   Установленный **Python 3.7+**.

### Установка

1.  **Клонируйте репозиторий** (или скачайте файл `iluzion.py`).
    ```bash
    git clone https://github.com/your-username/iluzion.git
    cd iluzion
Установите необходимые зависимости.

bash
pip install -r requirements.txt
Зависимости:

tkinter (Обычно встроен в Python)

Pillow

pywin32

pynput

keyboard

Запустите приложение.

bash
python iluzion.py
🎮 Как использовать
Первый запуск: Появится окно выбора языка. Выберите English или Русский.

Выберите вкладку: Используйте левую боковую панель для переключения функций.

Турбо: Выберите окно из списка и нажмите "Применить всё".

Качество: Включите "Растяжение" или "Motion Blur".

Комфорт: Настройте "Яркость".

Инструменты: Включите "Оверлей" или "Виджет ввода". Сделайте скриншот.

Запись: Начните/остановите запись экрана.

Прицел: Настройте и включите прицел.

Обратная связь: Отправьте отзыв.

Применение настроек: После настройки нужных параметров нажмите кнопку ▶️ Запустить внизу главного окна.

Остановка всего: Нажмите ⏹️ Остановить, чтобы отключить все активные функции.

Аварийный откат: Нажмите Ctrl+J, чтобы мгновенно сбросить все настройки.

Конфиги: Используйте верхнюю панель для создания Нового, Сохранения или Удаления конфигураций.

⚙️ Система Конфигов
Настройки сохраняются в JSON-файлы в папке:
Documents/Iluzion/Configs/

Конфигурация по умолчанию хранится в default.json. Вы можете создавать и переключаться между несколькими профилями.
